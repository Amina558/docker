     . A Dockerfile is a text file that contains a set of instructions for building a Docker image.

# 🉑Common Instruction
    ▶️some of the common instruction in a Dockerfile include:
    . FROM <image>: this specifies the base image that the built will extend 
    . RUN <command>: this instruction tells the builder to run the specified command 
    . ENV <name> <value>: this instruction sets an environment variables that a running container will use 
    . COPY: this instruction tells the builder to copy files from the host and put them into the container image 
    . WORKDIR <path>: this instruction specifies the "working directory" or the path in the image where files will be copied and commands  will execcuted
    . EXPOSE <port-number>: this instruction configuration on the image that indicates a port the image would like to expose.
